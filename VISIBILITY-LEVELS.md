## Public Record / Public Manifest

The full Self-Location Record and Index Manifest are publicly accessible.

## Restricted Record / Public Manifest

The canonical record contains restricted fields, but the submitter publishes an authorized public summary for indexing.

Restricted fields must not be copied into this public repository.

## Private Record / Permissioned Manifest

The record and manifest are available only inside a permissioned federation.

This public GitHub registry node does not accept private manifests.

## Visibility Rules

- Visibility must be declared.
- Public display must be authorized.
- Restricted fields must remain restricted.
- A registry may not infer consent from technical accessibility.
- Searchability does not equal permission to reproduce.
- A public index entry must not expose more than the submitted public manifest.
- A later visibility restriction must be recorded as an update rather than silently rewritten.
